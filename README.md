# Smart AI-Based Content Creation and Planning Application

## About the Project

An AI-powered content creation and planning application that generates
social media captions, scripts, vlog ideas, hashtags, and creative content
using artificial intelligence.

## Features

- User Authentication
- AI Content Generation
- Vlog Idea Generator
- Caption & Hashtag Generator
- Script Generator
- AI Image Generation
- Text-to-Speech
- Trend Analysis
- Content Planning
- Dashboard & Content Management

## Technologies Used
- Libraries(tensorFlow,pytorch)
- Image processing libraries
- Authentication and security modules
- Python
- Artificial Intelligence
